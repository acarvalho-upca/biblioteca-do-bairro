📚 Biblioteca do Bairro

Bem-vindo à Biblioteca do Bairro!

Este projeto consiste no desenvolvimento de um website para uma biblioteca local, com o objetivo de apresentar informações sobre a biblioteca e facilitar o acesso dos visitantes aos seus conteúdos.

🎯 Objetivos do Projeto

Criar um website simples e intuitivo.

Apresentar informações sobre a biblioteca.

Organizar os conteúdos de forma clara.

Desenvolver competências em HTML e CSS.

💻 Tecnologias Utilizadas

CSS3
